# Machine Health Intelligence — Frontend

Browser-based predictive maintenance dashboard using HTML, CSS, and vanilla JavaScript.

It imports machine sensor CSV files in the browser, calculates an explainable health score, and presents the maintenance priority queue. The sample CSV is included for the interface demo.

This public repository intentionally contains only frontend files. Python analysis code, server-side integrations, and deployment configuration are excluded.

## Run locally

Open `index.html` in a browser, then choose **Load demo data** or upload a compatible CSV file.
